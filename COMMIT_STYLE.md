# Commit Style

As of the introduction of this file, commits to the repository should be in the following format:

- the title should have the format `<subject>: <title>` (e.g. `jjfold: add initial property tests`)
- the title should be <=50 characters total
- there should be a description underneath the title, separated by a whitespace, but this is context dependent
- if there is a description, it should be <=72 characters per line

Ideally, the `<title>` after the `<subject>` starts with a present tense verb as well (e.g. `add`,
`delete`, `ensure`, `enforce`, `modify`).
