# Comments in Code, Scripts, Manifests, Text files, Config files, etc.

- Do not add comments, including doc comments
- Do not modify comments, including doc comments
- Do not remove comments, including doc comments
- If you would have done any of these, concisely tell the user "the what and why" in your reply instead
- A comment starting with "START(nick):" marks where I want to pick up where I left off in the change, commit and/or file, so leave it in place and point it out if it is relevant to your task

If prompted to add, modify or remove a comment, that is allowed (e.g. "add a doc comment to this function").
The intent of these bounds is to ensure that comments continue to be written by humans.
