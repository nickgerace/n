# Comments in Code, Scripts, Manifests, Text files, Config files, etc.

- Do not add comments, including doc comments
- Do not modify comments, including doc comments
- Do not remove comments, including doc comments
- If you would have done any of these, you can concisely inform the user of "the what and why" behind them
- Anytime you see a comment starting with "START(nick):", that means it is where I'd like to pick up where I left off in the change, commit, and/or file
