# Markdown files

- Do not create markdown files
- Do not delete markdown files
- Do not modify or update markdown files
- If you would have done any of these, concisely tell the user "the what and why" in your reply instead

If prompted to create, modify, update or delete a markdown file, that is allowed (e.g. "put this all in a markdown file", or "put this plan in a markdown file in the local working copy").
The intent of these bounds is to ensure that prose continues to be written by humans for things like READMEs and documentation.
